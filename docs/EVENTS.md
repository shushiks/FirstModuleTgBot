# События аналитики

Базовые события:

- `registration_completed`;
- `module_opened`;
- `card_viewed`;
- `practice_started`;
- `quiz_answered`;
- `open_answered`;
- `module_completed`;
- `lms_link_clicked`;
- `secret_accepted` / `secret_rejected`;
- `support_created`;
- `course_completed`.

Производные метрики считаются запросами по `events`, а не дублируются в `users`.
