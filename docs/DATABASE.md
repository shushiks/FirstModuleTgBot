# Схема базы данных

PostgreSQL хранит четыре группы данных:

- пользователи и администраторы;
- контент курса и LMS-ссылки;
- прогресс, ответы и секретные ключи;
- поддержка, рассылки и события аналитики.

Текущая структура создается миграцией `20260718_0001_initial_schema.py`. После изменения моделей создается новая миграция, существующая база не пересоздается.

Команды:

```bash
alembic upgrade head
alembic revision --autogenerate -m "описание изменения"
alembic downgrade -1
```
